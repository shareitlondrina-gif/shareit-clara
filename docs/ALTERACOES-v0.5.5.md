# Alterações — Clara v0.5.5

## Motivo

Consolidar a revisão funcional pedida para a Clara, registrar formalmente o papel das Integrações, revisar a aderência dos indicadores às telas aprovadas e entregar um **manual ilustrado de usabilidade** dentro do pacote.

## Entregas desta versão

- Inclusão do documento `docs/REVISAO-FUNCIONAL-v0.5.5.md`;
- Inclusão do manual `docs/MANUAL-USABILIDADE-ILUSTRADO-v0.5.5.md`;
- Inclusão do manual em PDF `docs/MANUAL-USABILIDADE-ILUSTRADO-v0.5.5.pdf`;
- Inclusão da pasta `docs/ManualIlustrado/Imagens` com as telas de referência e capturas de apoio usadas na revisão;
- Atualização dos identificadores de versão do pacote para `0.5.5`.

## Diretriz funcional consolidada

A Clara deve priorizar a leitura prática de negócio:

1. quem está trabalhando;
2. no que está trabalhando;
3. o que trabalhou hoje;
4. quais evidências sustentam a leitura;
5. quais oportunidades gerenciais podem ser acionadas.

## Banco

Nenhuma migration nova foi adicionada nesta versão. As 6 migrations existentes permanecem no pacote.
